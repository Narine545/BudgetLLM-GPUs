# Локализация

Русский — исходный язык базы: тексты лежат прямо в данных, разметке и коде интерфейса.
Английский и китайский подключаются словарями в `assets/i18n/`. Никаких сборщиков,
никаких сетевых запросов: словари — обычные `<script>`-файлы, как и данные.

## Как это работает

```
assets/js/i18n.js      рантайм: список языков, BLDL.tr(), правила, переключатель
assets/i18n/en.js      словарь английского
assets/i18n/zh.js      словарь китайского
```

* **Ключ словаря — русская строка целиком**, ровно в том виде, в каком она попадает
  в текстовый узел: `"Каталог карт": "GPU catalog"`.
* **Строки с числами** описываются правилами подстановок: `["Показано {0} из {1} карт", "Showing {0} of {1} cards"]`.
  `{0}`, `{1}` — позиции, в которые подставляются куски исходной строки.
* **Чего нет в словаре — остаётся по-русски.** Это осознанное поведение: база работает
  при любом покрытии перевода, а не ломается от одной забытой строки.
* **Единицы и сокращения** (`ГБ`, `ГБ/с`, `Вт`, `ток/с`, `Тфлопс`, `мин`) переводятся
  отдельным списком `UNITS` в `i18n.js` — только для коротких подписей вроде «24 ГБ»,
  чтобы в длинных предложениях не получалось смеси языков.
* **Переключатель** — инлайн-флаги в SVG в шапке. Выбор хранится в `localStorage`
  (`bldl-lang`), при первом запуске берётся язык браузера, по умолчанию — русский.
* **Атрибуты** `title`, `aria-label`, `placeholder` переводятся вместе с текстом;
  содержимое `<code>`, `<pre>` и скриптов не трогается никогда.

## Инструменты

```bash
npm run i18n                     # покрытие: сколько строк переведено
npm run i18n -- --missing en     # что осталось перевести (с путями по данным)
npm run i18n -- --list           # все строки, которые вообще нужно перевести
npm run i18n -- --skeleton de    # черновик словаря для нового языка
```

`--skeleton` создаёт `assets/i18n/_skeleton-de.js` со всеми русскими строками базы и
пустыми значениями. Его нужно заполнить, переименовать в `de.js`, подключить в
`index.html` (`<script src="assets/i18n/de.js"></script>`) и добавить язык в список
`BLDL.langs` внутри `assets/js/i18n.js`. Больше ничего: интерфейс сам обойдёт страницу
и переведёт всё, что найдёт в словаре.

## Правила перевода

* Названия карт, моделей, движков и утилит (`CMP 170HX`, `llama.cpp`, `MI50`) не переводятся.
* Числа и единицы сохраняют исходный смысл: «8 ГБ → 64 ГБ» это «8 GB → 64 GB», а не «64 GB».
* Пометки достоверности (`замер`, `отчёт`, `оценка`, `паспорт`) переводятся строго
  одинаково во всех местах — на них опирается доверие к цифрам.
* Команды, пути и вывод терминала остаются как есть.

## Проверки

`node tools/validate.js` дополнительно следит за тем, чтобы список языков совпадал с
набором словарей, словари были подключены в `index.html` и содержали секции `strings`
и `rules`. `npm run smoke` в jsdom проверяет сам переключатель: три языка, инлайн-флаги,
смена подписей при клике и корректный возврат к русскому.
