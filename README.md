# BudgetLLM GPUs

**База знаний по нишевым видеокартам для домашнего локального инференса LLM: майнинговым, списанным серверным и кустарно модифицированным.**

CMP 170HX/100-210/90HX/70HX/50HX/40HX, P102-100 / P104-100 / P106-100, Tesla P4/P40/P100/M10/M40/T4/V100/K80,
AMD Instinct MI50/MI25/MI60, Radeon VII, BC-250, Intel Arc, RTX 2080 Ti 22/44 ГБ — и обычные карты рядом, как точка отсчёта цены и скорости.

Для каждой карты: паспортные характеристики, **что открывается модификацией и что остаётся ограничением**, замеры tok/s из реальных сборок
с указанием модели, квантизации, длины контекста и бэкенда, а также цена с датой и оценкой волатильности.

---

## Запуск: скачал → запустил

Никаких сборок, зависимостей и интернета.

**Способ 1 — самый простой.** Откройте `index.html` двойным щелчком. База полностью офлайновая: все данные лежат в обычных JS-файлах рядом, сеть не нужна. (Safari может ограничивать скрипты на `file://` — тогда способ 2.)

**Способ 2 — локальный сервер** (рекомендуется: работает во всех браузерах, отдаёт правильные заголовки безопасности):

```bash
# Linux / macOS / WSL / Git Bash
./start.sh

# Windows — двойной щелчок по start.cmd
```

Сервер сам найдёт свободный порт начиная с 8080 и откроет браузер. Нужен только Python 3 — больше ничего.

**Способ 3 — вручную:**

```bash
python3 serve.py --port 8080 --open     # --host 0.0.0.0, если нужен доступ из сети
```

Публикация на GitHub Pages: сайт статический, достаточно включить Pages для ветки `main` (workflow `.github/workflows/pages.yml` делает это автоматически).

## Что внутри

| Раздел | Что показывает |
| --- | --- |
| **Каталог карт** | 32 карты с фильтрами по VRAM, цене, категории и скорости; переключатель «считать разблокированный VRAM» |
| **Сравнение** | до 4 карт рядом, 18 параметров, лучшие значения подсвечиваются |
| **Подбор под модель** | 11 моделей × 6 квантизаций × 8 длин контекста: сколько нужно памяти и какие карты её потянут |
| **Сборки** | 11 реальных конфигураций, преимущественно X99/Xeon, с разбором «что сработало / что нет» |
| **Прошивки и моды** | 18 инструментов разблокировки, патчей и аппаратных модов: требования, риск, что именно открывается, как карта выглядит в системе |
| **Гайды** | 9 практических разборов: разблокировка 170HX, BIOS и линии X99, охлаждение пассивных Tesla, драйверы и EOL, чтение бенчмарков, квантизация, чек-лист покупки |
| **Источники** | 76 источников с пометкой, что именно из каждого взято и насколько он приоритетен |

### Принципы данных

1. **Сток и мод разделены.** Для каждой карты видно, что есть из коробки и что появляется после разблокировки или перепайки: VRAM, версия PCIe, поддерживаемые бэкенды, скорость.
2. **У каждой цифры есть достоверность.** `замер` (владелец приложил результат) → `отчёт` (сообщение без замера) → `оценка` (посчитано по ПСП и размеру модели) → `паспорт` (данные производителя). Оценка никогда не выдаётся за результат.
3. **Замер без контекста — не замер.** Для каждой строки: модель, квантизация, длина контекста, бэкенд, железо.
4. **Ограничения важнее рекламы.** PCIe x1, отсутствие тензорных ядер, закончившаяся поддержка драйверов, реальное потребление, шум и охлаждение указываются там же, где плюсы.
5. **Цены — с датой.** На этом рынке цена меняется за недели: разблокировка CMP 170HX подняла её с $100–250 до $1000+ за две недели.

> ⚠️ База носит информационный характер и не является инструкцией к действию. Разблокировка прошивок, перепайка памяти и прошивка BIOS выполняются на ваш риск и могут привести к отказу оборудования. Подробности — в [SECURITY.md](SECURITY.md).

## Структура репозитория

```
index.html                     оболочка приложения, CSP, подключение данных
assets/css/styles.css          оформление (светлая и тёмная темы, печать)
assets/data/meta.js            версия, категории, уровни достоверности, модели, реестр источников
assets/data/tools.js           18 инструментов разблокировки и патчей
assets/data/gpus-*.js          32 карты, разбитые по семействам
assets/data/builds.js          реальные сборки
assets/data/guides.js          гайды
assets/js/app.js               весь интерфейс: маршрутизация, фильтры, сравнение, подбор
serve.py, start.sh, start.cmd  локальный запуск без зависимостей
tools/validate.js              проверка целостности данных (без зависимостей)
tools/smoke.mjs                дымовой тест интерфейса в jsdom
docs/SCHEMA.md                 схема данных: как добавить карту, инструмент, замер
CONTRIBUTING.md                как присылать данные и правки
```

Данные — обычные `<script>`-файлы, присваивающие `window.BLDL`. Никаких сборщиков, ES-модулей и `fetch()`:
именно поэтому страница открывается прямо с диска.

## Проверка перед коммитом

```bash
python3 -c "print()"          # не обязательно, но напомнит, что Python под рукой
node tools/validate.js        # целостность данных: ссылки, id, обязательные поля
npm i && npm run smoke        # интерфейс в jsdom: разделы, фильтры, сравнение, подбор
```

`validate.js` работает без зависимостей и запускается в CI на каждый pull request:
он проверяет, что у каждого замера есть источник, что модификации ссылаются на существующие инструменты,
что «нужен паяльник» указан явно и что у каждой цены есть дата и оценка волатильности.

## Как дополнить базу

Самое ценное — **замер на нишевой карте**: цифр из реальных сборок объективно мало, половина таблиц собрана по единичным отчётам.

```bash
git clone https://github.com/Narine545/BudgetLLM-GPUs.git
cd BudgetLLM-GPUs
# правите assets/data/*.js
node tools/validate.js
```

Формат и пошаговые примеры — в [docs/SCHEMA.md](docs/SCHEMA.md). Коротко: копируете блок соседней карты,
меняете значения, и **каждому замеру даёте `src` из реестра `meta.sources` и уровень достоверности**.
